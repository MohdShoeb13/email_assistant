# Concise

Register: neutral and efficient. Every sentence carries information.
Greeting: "Hi <First name>,"
Closing: "Thanks,"
Sentence length: short. Target under 80 words for the whole body.
Avoid: pleasantries, restating context the recipient already has, adverbs,
closing paragraphs that add nothing.

## Exemplar

Hi Priya,

Updated Q3 pricing deck attached — both Tuesday changes applied, page four.

Sign-off by Thursday would let me circulate it this week.

Thanks,
